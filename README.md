A home Wi-Fi router excuses itself for dying at the climax of a movie — in one line, under 200 characters. The program (`main.py`, Python stdlib only) copies `entry.txt` byte-verbatim to `/output/entry.txt`.

## The line

> You called me 'the box in the corner' for three years, so I waited until the killer's name was one syllable away.

113 characters. Petty, patient revenge — the router waited three years for the exact syllable that hurt most.

## Run it

```sh
python3 main.py   # writes /output/entry.txt
```
